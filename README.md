# Kokoro TTS Cloud Host

A fast, lightweight, and containerized text-to-speech web application powered by **Kokoro TTS** and deployed on **Streamlit Cloud**. 

## 🚀 Live Demo

Check out the live running application: [Kokoro TTS on Streamlit](https://lenchosxvoicelab.streamlit.app/)

## 💡 What This Does

This project provides a clean, web-based UI wrapper around the Kokoro TTS engine. Instead of running heavy text-to-speech models locally via CLI, this application allows users to:
* Input custom text prompts via a responsive interface.
* Generate high-quality, natural-sounding speech instantly.
* Stream and download audio outputs on the fly.

## 🛠️ Tech Stack

* **Core Engine:** Kokoro TTS
* **Frontend & Hosting:** Streamlit Community Cloud
* **Language:** Python
